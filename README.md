**Capstone projects**

- **[Geges Smart Barber](https://github.com/MyCampusLab/capstone-pt1)** — A multi-tenant barbershop platform I built as my first capstone. Customers can book, join a live queue, buy products, and chat with the admin. The queue engine distributes work among barbers fairly based on monthly load. Flutter mobile client + React web admin + real-time Firestore sync. This is the kind of product I want to build for real.

- **[VisionSafe](https://github.com/MyCampusLab/capstone-pt2)** — On-device eye-fatigue detection built with MediaPipe Face Mesh. Measures the Z-coordinate of the user's eyes relative to the screen and triggers a blur overlay when distance drops below 30cm. Runs as a background Android service without sending any data to a server. Built with Marsha.
